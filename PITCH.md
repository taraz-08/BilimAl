# BilimAI — Интеллектуальная образовательная платформа

> **"Каждый студент заслуживает персонального наставника. BilimAI делает это реальностью."**

---

## Что такое BilimAI?

BilimAI — это веб-платформа для казахстанских университетов, которая использует искусственный интеллект для автоматизации учебного процесса: от создания тестов до анализа успеваемости каждого студента.

Представьте: преподаватель загружает тему или PDF-документ → система сама генерирует тест → студент проходит его под наблюдением AI-прокторинга → система автоматически проверяет ответы, выставляет оценки и даёт персональные рекомендации. Всё это — без ручного труда преподавателя.

---

## Проблема, которую мы решаем

Казахстанские университеты сталкиваются с тремя системными проблемами:

| Проблема | Реальность |
|---|---|
| Преподаватель тратит 40–60% времени на рутину | Составление тестов, проверка работ, ведение журналов |
| Нет персонализации обучения | Все студенты получают одинаковую программу |
| Академическая нечестность | Списывание на тестах, использование телефонов |

BilimAI решает все три проблемы одним продуктом.

---

## Для тех, кто не знает программирование

Представьте, что у каждого преподавателя есть умный помощник, который:

- 📝 **Сам составляет тесты** — достаточно сказать тему или загрузить документ
- 📷 **Следит за честностью** — камера на экзамене автоматически замечает, если студент достал телефон
- 📊 **Анализирует каждого студента** — кто отстаёт, кто успевает, кому нужна помощь
- 🖊️ **Читает рукописные работы** — фотографируете тетрадь, AI прочитает и поставит оценку
- 💬 **Даёт советы студентам** — персональные рекомендации на казахском языке

Всё это работает через обычный браузер — никакого специального оборудования не нужно.

## Для технических специалистов

### Архитектура системы

```
Frontend              Backend               AI Services
─────────────         ─────────────         ─────────────
React 18 + Vite  ──►  FastAPI (Python) ──►  Google Gemini 2.5 Flash
Tailwind CSS          SQLAlchemy ORM        Google Vision API
face-api.js           SQLite / PostgreSQL   TensorFlow.js (COCO-SSD)
TensorFlow.js         JWT Auth
framer-motion         REST API
```

### Технологический стек

**Backend:**
- **FastAPI** — высокопроизводительный Python-фреймворк, автодокументация OpenAPI
- **SQLAlchemy** — ORM с поддержкой миграций, легко масштабируется на PostgreSQL
- **Google Gemini 2.5 Flash** — генерация тестов, проверка письменных ответов, персональные рекомендации
- **Google Cloud Vision API** — OCR рукописного текста (DOCUMENT_TEXT_DETECTION)
- **JWT-аутентификация** — токены в заголовках, роли student/teacher

**Frontend:**
- **React 18 + Vite** — быстрая сборка, code splitting
- **face-api.js** — клиентская детекция лиц (tinyFaceDetector, 190KB модель)
- **@tensorflow-models/coco-ssd** — детекция телефонов через COCO-SSD на клиенте
- **Framer Motion** — анимации интерфейса
- **i18n** — три языка: қазақша / русский / English

### AI-модули

| Модуль | Технология | Описание |
|---|---|---|
| Генерация тестов | Gemini 2.5 Flash | По теме или PDF-документу |
| Проверка ответов | Gemini 2.5 Flash | Письменные ответы с обратной связью на казахском |
| Прокторинг — лицо | face-api.js (клиент) | Обнаружение отсутствия/множества лиц |
| Прокторинг — телефон | COCO-SSD (клиент) | Детекция class "cell phone", скриншот → учителю |
| OCR рукописей | Google Vision API | DOCUMENT_TEXT_DETECTION |
| Рекомендации | Gemini 2.5 Flash | Персонализированные советы на казахском |
| Предсказание риска | Rule-based ML | good / average / risk на основе баллов и посещаемости |
| Анализ транскрипта | PDF парсинг + regex | СКПУ формат, GPA, сильные/слабые предметы |

### Безопасность и прокторинг

```
Начало теста
    │
    ▼
Fullscreen enforcement ──► выход → предупреждение
    │
    ▼
Camera stream (getUserMedia)
    │
    ├──► face-api.js (каждые 2.5с)
    │         ├── нет лица → предупреждение
    │         └── несколько лиц → предупреждение
    │
    ├──► COCO-SSD (каждые 2.5с)
    │         └── телефон > 50% confidence → скриншот → backend → учитель
    │
    └──► Tab visibility API → смена вкладки → предупреждение

3 нарушения → автосдача + блокировка
```

## Рынок и масштабирование

**Целевая аудитория — первая волна:**
- Казахстанские университеты (130+ вузов)
- Технические колледжи (300+)
- Онлайн-курсы и центры подготовки

**Потенциал рынка:**
- ~600 000 студентов в казахстанских вузах
- Аналоги (Google Classroom, iSpring) не имеют казахскоязычного AI
- Нет локального решения с прокторингом + OCR рукописей

**Модель монетизации:**
- SaaS подписка на университет (по количеству студентов)
- Freemium для преподавателей (до 50 студентов бесплатно)
- B2G — государственные университеты по тендеру

**Масштабирование технологии:**
- SQLite → PostgreSQL (одна строка конфига)
- Добавление новых AI-моделей без изменения архитектуры
- Docker-контейнеризация готова к облаку (AWS / Yandex Cloud)

## Команда

Проект разработан в рамках AI-хакатона. Стек выбирался осознанно:

- **FastAPI** вместо Django — в 3x быстрее, нативная OpenAPI документация, идеален для AI-микросервисов
- **Gemini 2.5 Flash** вместо GPT-4 — дешевле, быстрее, работает с казахским языком
- **face-api.js на клиенте** — не отправляет видео на сервер, приватность студентов защищена
- **COCO-SSD на клиенте** — детекция телефона без серверных затрат
